CURATERS WHOLE-SITE DESIGN PREVIEW

Files:
- index.html: Day Trips
- private.html: Private Trips
- group-trips.html: Group Trips
- hosted-trips.html: Hosted Trips
- curaters-preview.css: shared responsive styling
- assets/images/: original logo assets

HOW TO TEST ON ANDROID
1. Extract this ZIP into a folder.
2. Open index.html with your browser or a local HTML preview app.
3. Use the four category tabs to move between local preview pages.
4. Test on phone width and rotate the screen to check responsiveness.

IMPORTANT LIMITATIONS
This is a visual preview made from downloaded HTML responses. It does not include the PHP backend or private server logic. The private access form is deliberately preview-only and will not submit an access key. Trip detail links open the live Curaters website because those detail pages were not included in the ZIP. Some original page content embeds media directly as Base64; that content was retained.

The original downloaded files are not changed by this package. Review the preview before deployment. GitHub Pages cannot execute PHP, so this package is for design review only, not a replacement for the live PHP site.
